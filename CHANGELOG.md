# Bitácora de Cambios 

Todos los cambios notables en este proyecto serán documentados en este archivo. Este proyecto sigue el estándar de [Conventional Commits](https://www.conventionalcommits.org/).

## [0.1.0] - 2026-05-30

### Added (Nuevas funcionalidades)
- Implementación de la estructura base del repositorio.
- Configuración inicial de paridad de entornos (.env.example).
- Integración de flujo de trabajo básico (CI/CD).
- Módulo de control de progresión académica (HU-02).

### Changed (Modificaciones)
- Estructuración de ramas bajo estándar GitFlow.
- Ajuste de políticas de seguridad para ramas protegidas (main).

### Fixed (Correcciones)
- Resolución de errores en renderizado de diagramas Mermaid en README.
